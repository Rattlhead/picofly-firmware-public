# PicoFly: краткая инструкция мастеру

## Перед началом

- Используйте только USB/BOOTSEL. Для BY25Q20AW нельзя применять console update и rollback.
- Сохраните свой recovery-файл до окончания работы.
- Перед серией подпишите плату: `тонкий` или `толстый` текстолит.
- Не смешивайте обычные 2.x и диагностические FlashDiag 3.x в одной серии.

## LED-диагностика 2.x

- Для обычной проверки используйте 2.81, затем 2.82 и 2.83.
- Ошибка в 2.81–2.83: три фиолетовых импульса категории, пауза 1,5 с, четыре красных импульса причины, пауза 3 с и повтор.
- 2.99 используйте отдельной диагностической серией: после красных импульсов есть ещё пауза 1,5 с и четыре синих импульса контекста. Запишите весь ритм и паузы.

## FlashDiag 3.x: что записывается

Выберите одну версию на серию: 3.01 для базы 2.74 или 3.02 для базы 2.80. Выполните три запуска консоли с полным отключением питания между ними, затем снова войдите в BOOTSEL и выгрузите журнал.

FlashDiag трассирует четыре линии: **RST, CLK, CMD и DATA0**. В отчёте также будут параметры glitch-циклов, необработанный журнал и необработанная трасса.

## Windows: программа и драйвер

1. Скачайте и распакуйте [FlashDiag Exporter для Windows](picofly-lab/artifacts/packages/FlashDiag%20Exporter-Windows-x64.zip). Python и `picotool` устанавливать не нужно.
2. Один раз настройте драйвер: войдите в BOOTSEL, убедитесь, что виден `RPI-RP2`, скачайте [Zadig](https://zadig.akeo.ie/), в `Options` → `List All Devices` выберите только `RP2 Boot (Interface 1)`, назначьте `WinUSB` и нажмите `Install Driver`.
3. Не меняйте `Interface 0` и драйвер диска `RPI-RP2`.
4. В распакованной папке откройте `cmd` и выполните `"FlashDiag Exporter.exe"`.
5. В меню выберите `1 — Проверить подключение PicoFly`, затем `2 — Выгрузить диагностический журнал`.

Программа сохранит отчёт в `FlashDiag_Reports` рядом с собой. При полном журнале она очистит только область диагностики; при ошибке или неполном журнале ничего не стирается.

## Что отправить разработчику

Отправьте архив всего каталога из `FlashDiag_Reports`, не меняя файлы внутри. К имени **копии** каталога добавьте `тонкий__` или `толстый__`.
