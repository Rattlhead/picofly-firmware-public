# Инструкция для тестировщика PicoFly Data0Lab

Этот файл сгенерирован из `firmware-lab/firmware-profiles.json`; не редактировать вручную.

Для обычной серии разрешены 2.81, 2.82 и 2.83. Профиль 2.99 предназначен только для отдельной диагностической серии мастера. Версии со статусом `blocked-by-measurement` не прошивать.

| Прошивка | Изменение относительно родителя |
| --- | --- |
| 2.81 | Алгоритмы 2.80, расширенная LED-диагностика |
| 2.82 | 010-dat0-filter.patch; 011-dat0-hysteresis.patch |
| 2.83 | 012-pio-reset.patch |
| 2.99 | 022-led-context-diagnostics.patch |

Для каждого buildable-профиля выпускается один проверенный `clean-install` UF2 для USB/BOOTSEL. Он содержит односекционный загрузчик BY25Q20AW и прошивку; console updater и rollback не выпускаются и не поддерживаются. Имя файла включает версию и краткое назначение.

Жёлтый legacy-код 2.80 сохранён в коде, но не выводится. В 2.81–2.83 ошибка содержит 3 фиолетовых бита категории и 4 красных бита причины. В 2.99 после ещё одной паузы 1,5 с следуют 4 синих бита контекста; полный кадр повторяется после 3 с. На одноцветном Pico записывайте ритм и паузы.

На каждом образце: 30 холодных запусков 2.81, 30 — 2.82, 10 — 2.81, 30 — 2.83, 10 — 2.81. Диагностическую серию 2.99 проводите отдельно и фиксируйте полный трёхполевой код. Для каждого запуска записывайте версию, CRC, результат, время, LED-ритм и восстановление через USB/BOOTSEL.
